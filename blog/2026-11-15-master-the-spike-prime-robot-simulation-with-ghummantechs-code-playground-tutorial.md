## Accessing the Code Playground
To get started, open your browser and navigate to [comment.com](https://comment.com). Once there, click on the **menu tab** and look for the **Tools** section. You'll find the **Code Playground** listed as the second option. 

Here's what you’ll see when you land in the playground:

1. **Python Playground Tab**: Write and run Python code directly.
2. **Robot Simulation Tab**: Simulate robot behavior without hardware.
3. **Spike Prime Lab Tab**: Connect to your actual Spike Prime via Bluetooth for real-world control.

## Writing Your First Python Code
Let’s start by writing a simple Python script in the first tab. For example:

```python
print("Hello, World!")
```

To execute this code, click the **Run** button. You’ll see output in the console below.

> 💡 Tip: In Python, always call functions explicitly (like `print()`), otherwise they won't execute unless invoked.

## Controlling Your Robot with Spike Prime Lab
Now let’s explore how to control your physical Spike Prime robot using the **Spike Prime Lab** tab. 

### Connecting via Bluetooth
Before controlling anything, make sure:
- Your Spike Prime is powered on.
- It's within Bluetooth range (usually up to 10 meters).

Click **Connect** in the lab interface — you’ll be prompted to allow Bluetooth permissions. Once connected, you’re ready to simulate or control movements.

### Manual Control Using Arrow Keys
In this mode, you can manually drive your robot using arrow keys:

- Press and hold the **up arrow key** to move forward.
- Release it to stop.
- Use the **left/right arrows** for turning.

Once you’ve moved the robot, scroll up to find the **Add Motion Step** button. Clicking this adds your movement to the code list automatically.

### Example: Drawing a Square
Here’s how to create a square path:
1. Move forward → press **up arrow key**, then click **Add Forward**
2. Turn right 90 degrees → press **right arrow key**, then click **Add Turn**
3. Repeat steps 1 and 2 three more times

This process builds an accurate square path using intuitive controls.

## Simulating Without Hardware
If you don’t have access to a Spike Prime, the **Robot Simulation** tab is perfect for testing your logic.

You can:
- Run pre-defined programs
- Modify motion paths manually
- Add steps and watch real-time simulation

The simulation uses **yaw angle-based turns**, which are extremely precise — ideal for tasks requiring accuracy like navigation or mapping.

## Programming Precision with Angles
One of the standout features of Code Playground is its ability to define custom angles instead of fixed movements. For instance:

Instead of moving forward and then turning 90 degrees, you can set a turn to exactly **45 degrees**.

This gives developers full control over robot trajectories and makes it easier to create complex mazes or paths.
