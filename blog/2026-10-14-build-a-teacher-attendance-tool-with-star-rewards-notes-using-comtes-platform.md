## Introduction

Managing class attendance and recognizing student participation can be time-consuming for teachers. But what if you could automate attendance tracking, reward students with virtual stars, and take real-time notes all in one seamless tool? In this tutorial, we’ll walk through how to use Comte’s **Class Attendance & Stars** tool to create an efficient, interactive, and rewarding classroom experience.

## Getting Started with the Tool

To begin, navigate to the **Tools** section by clicking on the hamburger menu (☰) in your Comte dashboard. Once inside the tools list, scroll down to find the **Class Attendance and Stars** tool. This dual-purpose feature allows teachers to track attendance and give students virtual stars as a form of recognition.

### Creating a New Class or Session

When starting a new class session, you have two options:

- **Create a new class**: Ideal for setting up a new group of students.
- **Add to today’s session**: Perfect if you’re continuing with an existing class.

## Adding Students and Customizing Avatars

Once inside the session, you’ll be prompted to add student names. Each student can have a unique avatar to personalize their presence in the system.

```bash
# Sample steps for adding students
1. Enter student name
2. Select an avatar from available options
3. Click "Add to Class Attendance"
```

You can add multiple students at once, and each one is saved automatically.

## Star Rewards System

One of the most engaging features of this tool is the **Star Rewards** system. Teachers can give individual students stars for participation, effort, or achievement. You also have options to:

- Give a star to a single student
- Give stars to all students at once
- Use the **Random Student Picker** to select one student who deserves recognition (great for fairness!)

### Example Use Case

Let’s say John answered a difficult question correctly and showed great participation. You can:

1. Click on John's name in the list
2. Select "Give Star"
3. Add a note like: _“Great job answering our difficult question!”_

## Notes & Tags

The tool also supports detailed notes, making it easy to document student progress and behavior.

### Pre-Populated Tags vs. Custom Notes

- **Pre-populated tags** offer quick selection for common behaviors (e.g., "Excellent work", "Helpful", "Needs Improvement")
- **Custom notes** let you write personalized feedback tailored to each student

```bash
# Example of a note entry
Student: Joe
Tag: Excellent Rating
Note: Joe contributed significantly during the group activity.
```

## Viewing History & Importing Students

You can return to past sessions by selecting a date from the history section. This is particularly helpful for:

- Reviewing attendance and notes from previous classes
- Importing student lists instead of manually entering them each time

This feature ensures that no data is lost, and your classroom records remain consistent and up-to-date.

## Best Practices & Tips

1. **Use the Random Picker**: When all students are equally deserving, use this feature to fairly select one student for a special recognition.
2. **Personalize Notes**: Custom notes help build stronger relationships with students by showing you pay attention to their unique contributions.
3. **Save Time with Imports**: For repeated classes, import student lists to avoid re-entering information.
